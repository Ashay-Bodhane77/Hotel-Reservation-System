Hotel Reservation System

A simple Java-based Hotel Reservation System that allows users to manage hotel room bookings through a console-based interface.

Features
Add customer details
Book hotel rooms
Check room availability
Check-in and check-out system
View booking records
Simple and user-friendly console interface
Technologies Used
Java
ArrayList
OOP Concepts
Sample Functions
Reserve a room
Cancel reservation
Display available rooms
Generate booking summary
